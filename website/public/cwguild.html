CENTRALIZED PAYOUT DISCLOSUREVerify the wallet, token, and transaction.

Rune Run does not use a game contract. Each attempt requires a direct, non-refundable transfer of exactly 500,000 CWGUILD to the project-controlled reward wallet. The server verifies each payment on Ronin and consumes it for one attempt; it never requests a token allowance. The entry fee is not escrowed and is not returned. Eligibility and results are decided by this server, and cashed-out rewards are sent from the same project-controlled wallet. The top cash-out is 2,000,000 CWGUILD. The payout ceiling is the reward wallet's current CWGUILD balance and refreshes after entries and payouts; a cash-out is sent only when that balance can cover it. On-screen rewards are provisional and unpaid until Cash Out; accepting another round puts the entire provisional reward at risk, and a loss or timeout forfeits it. Each wallet may buy up to five attempts per UTC day. The operator can pause payouts, and a server outage can interrupt a run.
