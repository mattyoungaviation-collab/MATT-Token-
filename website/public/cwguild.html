HOW IT WORKS

No new contract. No custody of player tokens.

  1. 01Hold The server reads your public CWGUILD balance on Ronin.
  2. 02Sign A plain-text wallet signature proves the connected address is yours.
  3. 03Run Memorize a longer signal each round, then follow the random start position and direction before the shrinking timer ends.

CENTRALIZED PAYOUT DISCLOSUREVerify the wallet, token, and transaction.

Rune Run does not use a game contract. Eligibility and results are checked by this server, and cashed-out rewards are sent from a project-controlled operator wallet. On-screen rewards are provisional and unpaid until Cash Out; accepting another round puts the entire provisional reward at risk, and a loss or timeout forfeits it. Each wallet gets one ladder attempt per UTC day. Total Rune Run payouts stop at 2,000,000 CWGUILD. The operator can pause payouts, and a server outage can interrupt a run. Never approve CWGUILD for this game—Rune Run does not need an allowance.
